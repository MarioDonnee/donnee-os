# Donnée Incremental Task

Execute the requested task incrementally.

Working principles:
- Do not rewrite the app.
- Do not change unrelated files.
- Preserve current behavior.
- Prefer small, testable steps.
- Follow AGENTS.md.
- Avoid scope creep.

Process:
1. Identify affected files.
2. Explain the implementation plan briefly.
3. Apply changes.
4. Provide test steps.
5. Provide a commit message.
