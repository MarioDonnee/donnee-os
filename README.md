# Donnée OS

Sistema operacional interno da Donnée para gestão inteligente de clientes, projetos, atividades, prazos, responsáveis e indicadores operacionais.

## Stack

- Backend: FastAPI + Python
- Frontend: React + Vite + TypeScript
- Banco: Supabase/PostgreSQL
- Auth: Supabase Auth
- UI: Tailwind + shadcn/ui

## Módulos do MVP

- Usuários e permissões
- Clientes
- Projetos
- Atividades
- Kanban
- Histórico de alterações
- Dashboard básico
